# homebrew-tap

Homebrew tap for [AgentManager](https://umechanhika.github.io/agent-manager-site/).

```sh
brew install --cask umechanhika/tap/agent-manager
```

Updates after installation are delivered in-app (Sparkle). To move to the latest cask version explicitly:

```sh
brew upgrade --cask agent-manager
```

The cask's `version` / `sha256` are updated automatically by the AgentManager release workflow.
